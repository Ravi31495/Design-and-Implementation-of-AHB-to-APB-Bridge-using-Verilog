# Design-and-Implementation-of-AHB-to-APB-Bridge-using-Verilog
An AMBA AHB-to-APB bridge converts high-speed, pipelined Advanced High-performance Bus (AHB) transfers into low-power, non-pipelined Advanced Peripheral Bus (APB) control and data signals using a Finite State Machine (FSM). It acts as an AHB slave on one side and an APB master on the other.
